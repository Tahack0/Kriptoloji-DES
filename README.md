# Kriptoloji DES

OpenCV, YOLOv8 ve DES kullanarak videoda tespit edilen bölgeler üzerinde çalışan eğitim amaçlı Python deneyi.

`python -m pip install -r requirements.txt` ile bağımlılıkları kur. Kendi giriş videonu betiğin yanına koy ve dosya adını betikte ayarla. Segmentasyon betiği birden fazla giriş dosyası bekler. YOLOv8 ağırlıklarını Ultralytics üzerinden edin veya yerelde aynı adlarla sağla.
